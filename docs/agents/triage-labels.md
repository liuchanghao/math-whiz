# Triage labels

Local ticket status uses the following vocabulary:

- `needs-triage`: the request has not been classified.
- `needs-info`: required information is missing.
- `ready-for-agent`: the ticket is sufficiently specified for implementation.
- `ready-for-human`: the next action requires a human decision or external dashboard access.
- `complete`: every acceptance criterion is verified and no implementation work remains.
- `wontfix`: the request will not be implemented.

Each status maps to exactly one local label with the same spelling.
