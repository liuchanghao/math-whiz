# Issue tracker

This repository uses local Markdown tickets because its Gitee remote does not establish an existing issue workflow.

- Store tickets under `.scratch/<feature-slug>/issues/`.
- Use one file per ticket, numbered from `01` in dependency order.
- Record blocking ticket numbers and titles in every ticket.
- Work only on tickets whose blockers are complete.
- Do not replace the per-ticket files with one combined implementation checklist.
