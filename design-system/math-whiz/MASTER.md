# 数学小达人设计系统

这份文件记录管理后台与移动应用共同采用的视觉方向。页面级规则如存在，应放在 `pages/` 下并覆盖本文件。

## 产品语境

- 管理后台属于内部操作界面：优先清晰、可靠、可扫描，品牌感来自精确的间距、状态和细节。
- 移动应用主要由孩子在平板上使用，同时支持手机：保持操作直观，并用数学符号与少量暖色增加亲和力。
- 两端共享品牌语言，但不强求相同密度。后台更紧凑，移动应用触控目标不小于 48×48。

## 视觉方向

- 主色：学习蓝 `#2456D6`；深色交互态 `#173FAE`。
- 暖色点缀：`#F4AA21`，只用于数学趣味元素、奖励或需要注意的信息。
- 页面背景：浅蓝灰 `#EEF3FB` / `#EDF3FF`；内容表面为白色。
- 正文：墨蓝 `#14213D`；次级文字 `#53627A`；边框 `#D9E2F0`。
- 成功：`#147A45` / `#E8F7EF`；错误：`#AE2B2B` / `#FFF0F0`。
- 阴影必须有向下偏移和柔和模糊，不使用发光或硬边投影。
- 圆角保持克制：后台 12–16px，移动应用 14–28px，避免卡片层层嵌套。

## 字体与层级

- 中文优先使用系统内高质量无衬线字体：PingFang SC、Noto Sans CJK SC、Microsoft YaHei。
- 标题使用更紧凑的字距和 800–900 字重；正文最小 14px，常规正文 16px。
- 不使用 Comic、手写体、渐变文字或等宽字体来制造“儿童感”或“技术感”。
- 标题直接表达任务，不在标题上方添加装饰性眉题。

## 组件与交互

- 所有输入框必须有可见标签、清晰边框和高对比焦点态。
- 主按钮使用学习蓝与白字；次按钮使用白底蓝色边框；危险操作使用红色文字或浅红反馈。
- 可点击项必须有 hover/pressed 反馈；禁用、加载、错误、成功与空状态都需清楚可辨。
- Web 动效控制在 150–300ms，并尊重 `prefers-reduced-motion`。
- React Native 使用 `Pressable`、Android ripple 与安全区容器。

## 响应式检查

- 管理后台至少检查 390px、768px、1024px、1440px。
- 窄屏表单改为单列，不允许横向滚动；按钮在复杂表单中优先铺满可用宽度。
- 移动应用同时适配手机与平板宽度，保留安全区，长内容可滚动，键盘不能遮挡输入与主操作。

## 禁止项

- 不使用 emoji 或混杂的 Unicode 字符代替图标；品牌中的数学 `∑` 与作为内容出现的算式除外。
- 不使用紫色渐变、玻璃拟态、硬阴影、过度黏土效果或无意义的装饰卡片。
- 不依赖颜色单独传达状态，不移除焦点轮廓，不使用低对比灰字。
