# 08 — 完成基础题型并生成报告

**What to build:** 让会员顺序完成一个由单选题、判断题和数字填空题组成的 10 题轮次，逐题幂等保存且不提前泄露答案，并在第 10 题提交后原子地评分并展示答题报告。

**Blocked by:** 07 — 答题轮次创建、恢复与放弃.

**Status:** ready-for-agent

- [ ] 移动应用可按轮次顺序作答单选题、判断题和数字填空题，并显示当前题号与总进度。
- [ ] 每道题首次成功确认后不再修改，API 拒绝跳过顺序或重写已确认答案。
- [ ] 每次答案写请求使用幂等编号；同编号、同请求返回原结果，同编号、不同内容返回状态冲突。
- [ ] 前 9 题提交只返回保存成功与下一进度，不返回对错、正确答案或解析。
- [ ] 数字填空按题目配置执行数值等价或指定格式判分。
- [ ] 第 10 题提交时锁定轮次，在单一 MySQL 事务中保存答案、为每题计算 10 或 0 分、完成轮次并生成报告；任一环节失败时全部回滚。
- [ ] 完成页展示 0–100 总分，报告详情展示会员答案、正确答案、对错和可用解析。
- [ ] 不同会员不能访问对方轮次或报告。
- [ ] 事务失败注入、重复提交、并发第 10 题和答案泄露防护具有 API + MySQL 集成测试。
- [ ] 移动应用具有完成一轮基础题并查看报告的用户可见流程测试。
