# 10 — 满分实物奖品

**What to build:** 使会员每次完成 100 分轮次时，都会基于本轮年级当时的当前奖品生成一条不可修改的获奖记录，并立即在移动应用展示奖品与线下领取说明。

**Blocked by:** 05 — 奖品管理与可答年级; 08 — 完成基础题型并生成报告.

**Status:** ready-for-agent

- [ ] 第 10 题结算确认总分为 100 时，在同一事务中创建与会员、轮次和奖品关联的获奖记录。
- [ ] 每个满分轮次最多产生一条获奖记录，网络重试或并发结算不会重复发奖。
- [ ] 不同满分轮次可以为同一会员重复授予同一奖品，不实现每人限制或库存限制。
- [ ] 获奖记录保留结算时的奖品名称、说明和线下领取说明文字快照，不随奖品后续修改而变化。
- [ ] 非 100 分轮次不产生获奖记录。
- [ ] 移动完成页在 100 分时展示纯文字奖品弹层和线下领取说明，非满分时不展示。
- [ ] 获奖记录及其快照没有修改或删除业务接口。
- [ ] 满分、非满分、重复提交、相同奖品多轮次和事务失败回滚具有 API + MySQL 集成测试。
- [ ] 移动应用具有完成满分轮次并看到奖品的关键流程测试。
