# 03 — 会员登录与密码管理

**What to build:** 使少量人工初始化的测试会员能够通过手机号和密码登录移动应用，安全恢复单设备会话，主动退出并在登录状态下修改密码。

**Blocked by:** 01 — 工程骨架与健康检查.

**Status:** ready-for-agent

- [ ] 会员使用内部稳定编号和唯一规范化手机号，一期只校验中国大陆 11 位移动号码。
- [ ] 一期不提供注册页面或创建会员 API；项目维护者可将已安全哈希的密码直接写入数据库初始化 1–2 个账号。
- [ ] 移动应用可使用手机号和密码登录，访问令牌和可轮换刷新令牌保存在操作系统安全存储中。
- [ ] 同一会员只有一个有效设备会话；新设备登录撤销旧会话，刷新令牌重放被拒绝。
- [ ] 移动应用重新启动时可恢复有效会话，会话无效时返回登录页。
- [ ] 会员可退出登录，撤销服务端会话并清除本地令牌。
- [ ] 会员可通过原密码和两次一致的新密码修改密码；成功后全部会话失效并要求重新登录。
- [ ] 会员连续登录失败 5 次后暂停登录 15 分钟，所有凭据失败使用不泄露账号状态的统一文案。
- [ ] 已停用会员无法登录或刷新会话。
- [ ] 认证 API 集成测试与移动登录/修改密码用户可见行为测试均通过。
