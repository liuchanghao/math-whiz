# 12 — 会员管理与只读答题记录

**What to build:** 使系统管理员可以查找、查看、启用和停用现有会员，并只读查看会员的完整答题记录，但永远无法通过管理后台修改或删除原始作答事实。

**Blocked by:** 02 — 系统管理员安全登录; 03 — 会员登录与密码管理; 09 — 算式输入与竖式计算.

**Status:** ready-for-agent

- [ ] 后台会员列表支持分页和按手机号精确查找，展示内部编号、手机号、状态和基本时间信息。
- [ ] 后台不提供创建会员、重置密码、找回密码或变更手机号能力。
- [ ] 系统管理员可启用或停用会员；停用时在同一事务中撤销所有会话，但不删除历史业务数据。
- [ ] 会员状态变更写入不可修改的脱敏审计记录。
- [ ] 答题记录列表可分页查看会员、年级、轮次状态、得分和关键时间。
- [ ] 答题记录详情只读展示固定题目顺序、五种结构化会员答案、正确答案、对错、得分与轮次时间。
- [ ] 管理契约、API 路由和后台界面都不存在修改或删除答题记录的能力。
- [ ] 审计和运行日志不记录密码、令牌、完整手机号或完整答案内容。
- [ ] API + MySQL 集成测试和 Playwright 流程测试覆盖会员停用、会话撤销、数据保留和答题记录只读性。
