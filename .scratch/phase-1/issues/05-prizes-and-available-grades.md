# 05 — 奖品管理与可答年级

**What to build:** 使系统管理员能够维护纯文字实物奖品并为年级设置唯一当前奖品，同时让已登录会员只看到已启用、题量充足且奖品就绪的可答年级。

**Blocked by:** 03 — 会员登录与密码管理; 04 — 年级与知识点管理.

**Status:** complete

- [x] 奖品只包含名称、说明、线下领取说明、启用状态和适用年级，不包含图片、价格、库存、地址、物流或领取状态。
- [x] 系统管理员可在后台创建、查看、修改、启用和停用奖品，并维护适用年级。
- [x] 系统管理员可为每个年级设置唯一当前奖品，只能选择已启用且适用该年级的奖品。
- [x] 停用当前奖品时，相关年级不再满足开放条件，不会默认切换到其他奖品。
- [x] 移动应用的年级选择页只显示已启用、关联至少 10 道不同已启用数学题，且存在有效当前奖品的年级。
- [x] 在题库任务尚未完成时，可使用集成测试数据验证年级开放条件，不降低题量约束。
- [x] 奖品和年级当前奖品变更写入脱敏审计记录。
- [x] API 集成测试和管理后台/移动应用用户可见测试覆盖可用与不可用组合。
