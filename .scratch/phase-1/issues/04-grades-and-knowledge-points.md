# 04 — 年级与知识点管理

**What to build:** 使系统管理员能够维护小学一至六年级和按年级组织的数学知识点，为题库分类和后续年级答题入口提供稳定目录。

**Blocked by:** 02 — 系统管理员安全登录.

**Status:** ready-for-agent

- [ ] 数据库预置小学一至六年级，每个年级具有稳定编号、名称、排序和启用状态。
- [ ] 系统管理员可在后台查看年级并修改名称、排序和启用状态，不创建一至六年级之外的任意年级。
- [ ] 系统管理员可创建、查看、修改、启用和停用知识点。
- [ ] 一个知识点可关联多个年级，且后台可见、可维护该关联。
- [ ] 已被数学题引用的年级和知识点不被物理删除，通过状态停用。
- [ ] 列表和写操作使用共享 Zod 契约与统一 API 响应包装。
- [ ] 年级和知识点变更在同一事务中写入脱敏审计记录。
- [ ] API + MySQL 集成测试和后台关键管理流程测试覆盖正常与冲突状态。
