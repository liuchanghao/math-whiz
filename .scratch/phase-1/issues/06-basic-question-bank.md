# 06 — 基础数学题题库

**What to build:** 使系统管理员可以建立和维护单选题、判断题和数字填空题，并将题目按年级、知识点、难度和状态组织，同时保证已用题目的历史内容不被改写。

**Blocked by:** 04 — 年级与知识点管理.

**Status:** ready-for-agent

- [ ] 系统管理员可创建单选题、判断题和数字填空题，题干、选项和解析只支持纯文字、换行和常用数学 Unicode 符号。
- [ ] 单选题至少有 2 个选项且只有 1 个正确选项；判断题只有布尔正确值；数字填空题可选数值等价或指定格式判分。
- [ ] 数字等价判分能安全处理整数、负数、小数和分数，并拒绝分母为零、非法符号和超长输入。
- [ ] 每道题可关联多个年级、多个知识点并指定一个主要知识点，难度为简单、中等或困难。
- [ ] 题目状态为草稿、已启用或已停用，只有已启用题进入抽题范围。
- [ ] 未进入任何轮次的题可修改；已进入轮次的题干、选项和正确答案不可修改，但可停用。
- [ ] 后台提供题目列表、查询、创建、详情、受限修改和启用/停用操作。
- [ ] 移动题目契约永远不返回正确答案或服务端判分配置。
- [ ] 关键题目变更写入脱敏审计记录。
- [ ] 纯领域判分测试、API + MySQL 集成测试和后台关键题库流程测试均通过。
