# 11 — 历史报告、错题本、收藏与获奖记录

**What to build:** 为会员提供简单可用的历史查看能力，可以回顾每次已完成的答题报告、曾答错的数学题、主动收藏的题目和满分获奖记录，而不引入掌握状态或复杂统计。

**Blocked by:** 09 — 算式输入与竖式计算; 10 — 满分实物奖品.

**Status:** ready-for-agent

- [ ] 会员可分页查看自己已完成的答题报告，并打开包含五种题型的报告详情。
- [ ] 已放弃轮次不进入答题报告列表。
- [ ] 每次轮次完成时，答错题目自动以“会员 + 数学题”唯一关系进入错题本，并更新首次/最近答错时间。
- [ ] 错题本只提供基本分页查看，不增加“已掌握”、复杂过滤或统计图表。
- [ ] 会员可幂等收藏和取消收藏数学题，并分页查看已收藏题目。
- [ ] 会员可分页查看获奖记录中的奖品文字快照和线下领取说明。
- [ ] 所有历史资源都按当前会员隔离，任意资源编号不能越权访问他人数据。
- [ ] 列表统一返回 `items`、`page`、`pageSize`、`total`，空列表使用稳定响应结构。
- [ ] 报告、错题、收藏和获奖历史具有 API 集成测试与移动用户可见行为测试。
