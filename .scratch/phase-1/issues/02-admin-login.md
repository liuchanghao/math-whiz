# 02 — 系统管理员安全登录

**What to build:** 交付一条完整的系统管理员认证链路：一次性初始化管理员后，可以在管理后台登录、恢复安全会话并退出，而且管理凭据与会员身份完全分离。

**Blocked by:** 01 — 工程骨架与健康检查.

**Status:** completed

- [x] 管理员使用独立数据模型、用户名和密码哈希，不与会员数据表或会话共用。
- [x] 一次性初始化流程可创建使用随机强密码的唯一系统管理员，不在日志中输出明文密码。
- [x] 管理员可通过后台登录页登录，成功后使用 Secure、HttpOnly、SameSite Cookie 保持会话。
- [x] 受保护的管理接口拒绝未登录、过期或无效的管理员会话，写操作具有 CSRF 防护。
- [x] 退出登录撤销服务端会话并清除客户端 Cookie。
- [x] 错误用户名、错误密码和已停用状态使用统一失败文案，不泄露管理员是否存在。
- [x] Nginx/API 可对管理员登录执行独立的严格频率和连续失败限制。
- [x] 登录成功与失败写入不可修改的脱敏审计记录。
- [x] API + 测试 MySQL 集成测试和后台关键登录流程测试均通过。

**Verification:** `pnpm check`；真实 MySQL 集成测试 7/7；真实 MySQL + API + 管理后台 Playwright 流程 1/1；最终 Standards/Spec 复审均无发现。
