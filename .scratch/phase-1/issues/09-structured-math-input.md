# 09 — 算式输入与竖式计算

**What to build:** 在已可完成的答题闭环中增加算式输入题和竖式计算题，让管理员可配置结构化答案，会员可通过专用数学键盘作答，API 可安全解析、保存并判分。

**Blocked by:** 08 — 完成基础题型并生成报告.

**Status:** ready-for-agent

- [ ] 系统管理员可创建算式输入题，并配置一个或多个可接受的结构化算式答案。
- [ ] 系统管理员可创建竖式计算题，配置按数位对齐的结构和最终正确结果。
- [ ] 数学键盘包含 0–9、加、减、乘、除、大于、小于、等号、小数点、删除、清空和确认，分数与括号使用专用控件。
- [ ] 算式输入提交结构化表达式和标准展示文本，服务端只通过受限语法解析和规范化判分，绝不执行会员输入。
- [ ] 解析和规范化测试覆盖运算优先级、括号、分数、小数、比较关系、多个可接受答案与非法/超长输入。
- [ ] 竖式输入保存完整过程格与最终结果，一期只按最终结果判定 10 或 0 分，不部分给分。
- [ ] 两种新题型完整支持题库状态、已用不可修改、轮次恢复、幂等提交和报告展示。
- [ ] 数学键盘和竖式输入在手机紧凑宽度、平板竖屏和平板横屏下可用，点击区域不小于 48 个逻辑像素。
- [ ] 后台录题、API 判分与移动作答/报告的端到端行为测试均通过。
