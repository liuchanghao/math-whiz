# 07 — 答题轮次创建、恢复与放弃

**What to build:** 让会员从可答年级创建一个由服务端持有的 10 题轮次，中途退出后恢复相同题目与进度，并能主动放弃或在 7 天后由 API 惰性转为已放弃。

**Blocked by:** 03 — 会员登录与密码管理; 05 — 奖品管理与可答年级; 06 — 基础数学题题库.

**Status:** ready-for-agent

- [ ] 会员可在移动应用选择可答年级并创建一个进行中轮次。
- [ ] 创建时一次性固定 10 道不重复数学题及其顺序，不建立固定试卷。
- [ ] 抽题默认使用 4 简单、4 中等、2 困难；某难度不足时从其他难度补齐。
- [ ] 每个难度先随机选择会员未答过的题，不足时选择该会员最久未看到的已答题，同轮任何阶段不重复。
- [ ] 数据库约束与事务共同保证一个会员最多有一个进行中轮次，并发创建不会产生双轮次。
- [ ] 新建轮次设置 7 天过期时间，API 在查询、恢复或新建时在事务内惰性处理过期，不引入 Worker 或定时任务。
- [ ] 移动应用重启后可恢复相同轮次、题目顺序和当前进度。
- [ ] 会员可确认后主动放弃轮次；已放弃轮次不能恢复或提交答案。
- [ ] 已放弃轮次不计分、不生成报告、不更新错题且不获奖。
- [ ] 抽题纯规则测试、API 并发/恢复/过期集成测试和移动轮次流程测试均通过。
